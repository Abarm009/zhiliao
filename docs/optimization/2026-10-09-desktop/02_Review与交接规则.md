## 2. 状态与放行

GATES.json 的 status 允许：
NOT_STARTED → IN_PROGRESS → READY_FOR_REVIEW → PASS / FAIL / BLOCKED / NOT_RUN。

READY_FOR_REVIEW 表示编码方已交接，绝不表示独立验收成功。
PASS 由独立审查写入，指当前模块明确范围。任何必需检查 FAIL、BLOCKED、NOT_RUN 均不放行。
不使用“基本通过”“带条件 PASS”跳过必需缺口。可列出不影响本模块目标的后续建议，但不能把硬要求降为建议。
审查环境不能运行原生或模型时，源码分析可以交付，运行必需项记 BLOCKED/NOT_RUN，不能拿作者报告替代。
失败后的修复使用原模块、原缺陷编号与新候选，不进入下一模块。

串行依赖：M0 → M1 → M2 → M3 → M4 → M5 → M6 → M7。
开始下一模块前核对上一模块 PASS 记录及其候选。若基线上有新增未解释修改，先清点并检查受影响门槛。
后续模块合法新增变化不意味着整条历史自动作废，但要标明哪些先前结论仍适用、哪些需回归；重大基础变化先复核相关门禁。

M0 是最小可行性门槛，M2/M3/M5 是完整能力门槛；前者不能取代后者。
M7 PASS 只表示本地发布准备完成。P06 实际递交、P07 商店收录、P08 赛事回执单列，不由本地测试代签。
原 P07 等要求保留，未得到外部结果时继续保留原状态，不伪造或悄悄删除。

## 3. 候选快照

每次交接必须能重建“审查的到底是哪一份”：
- candidate_id、base_candidate_id、源码 HEAD；有未提交修改则保存 diff 和所需未跟踪源文件清单/哈希。
- 受影响源文件内容 SHA-256 清单；包版本与内容摘要。不能只填 HEAD，因为当前工作区非干净。
- 宿主来源 SHA/发行标识、二进制哈希、依赖与构建工具、启动方法。
- 测试数据夹具标识、应用数据目录、模型/provider 标识和影响行为的配置开关，不包含秘密。
- 受影响先前门槛及回归结果。

建议目录：
docs/optimization/2026-10-09-desktop/reports/Mx_IMPLEMENTATION_rN.md
docs/optimization/2026-10-09-desktop/reports/Mx_REVIEW_rN.md
runtime/optimization/2026-10-09/Mx/rN/（日志、截图、回执、候选清单等）

没有 Git 提交权限或不适合提交时，可用完整内容清单与差异定位；不为制造“干净版本”覆盖用户修改。
Review 期间冻结该候选。发现并发变化先记录并重新确认审查快照；不在已经变化的内容上沿用原 PASS。

## 4. 每轮证据

编码方交付：
1. 实施报告：目标、改动文件、接口/数据迁移、桌面变化、未接通项。
2. 候选快照与可重复启动步骤。
3. 测试表：用例、输入、步骤、预期、实际、PASS/FAIL/BLOCKED/NOT_RUN、证据。
4. 原生桌面截图/操作记录及权威状态、动作回执、真实附件等相应读回。
5. 失败路径及重试/重启证据，不能只有正常路径。
6. 本模块覆盖及暂不覆盖的 T/U/G0/P 项。
7. 残留问题，不用测试总数掩盖真实模型、身份、附件缺口。

不把密钥、私有个人材料、完整原始敏感回复写进交接材料。
截图证明界面状态；磁盘/回执证明写入；真实模型记录证明模型参与；独立身份记录证明权限。证据类型不能混用。

## 5. Review 责任

审查者先读实现报告但不信任其中“通过”结论，检查源码差异与证据后独立复现必需场景。
运行测试只操作隔离数据；允许必要的构建/运行与失败注入，不修改生产代码来让测试通过。
报告以 P0/P1/P2/P3 缺陷严重性和必需/建议属性分别表达；即使缺陷较小，只要违反本模块硬验收仍需修复。
每条缺陷提供文件/行、触发步骤、预期/实际、影响、证据与最小修复方向。
Review 不顺手修业务；FAIL 后由实现方修复，再审。Review 文档与门禁/真实验收记录可更新。
若改变原 ACCEPTANCE.json 结论，保留此前版本和历史证据引用，并注明本次适用运行形态；不把历史后端 PASS 覆盖解释成原生 PASS。

## 6. 用户如何交接

发给构建会话：复制模块文件的“修改指令”代码块。
发回审查会话：复制“Review 指令”代码块，并附实现报告路径/固定版本。若同一工作区无需上传整个工程。
如果换机器或项目，只提供文字自述不够，须有可访问的候选文件/固定提交与证据。
每次 Review 末尾输出：结论、必修项、未测/阻塞、是否允许进入下一模块。
只有 PASS 才给出下一模块入口；不自动执行。
