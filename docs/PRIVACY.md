# 本地演示数据说明

知了维修协作当前提供本地开发演示，不提供生产认证或多租户服务。

- 默认身份、项目、空间和设备由项目演示种子生成。公开截图中的联系人、问题描述与附件为演示数据。
- 本地业务后端将任务和事件写入 SQLite，附件写入配置的证据目录；原生脚本使用宿主隔离存储。运行状态统一留在 `runtime/`，不随源码提交。
- 本次公开仓库只包含源代码、文档、应用包和经过筛选的比赛展示材料，不包含运行数据库、日志、密钥、模型权重或语音虚拟环境。
- 比赛视频的普通话旁白在本机生成；配乐为本次制作的原创器乐。未把录屏或旁白文案发送给外部语音服务。
- 真实模型、外部通知、设备或工单接入须另外配置并验证，不能从本地演示推断已经接通。

问题反馈：[GitHub Issues](https://github.com/Abarm009/zhiliao/issues)。本文件描述当前本地演示，不构成已上线服务的运行保证。
